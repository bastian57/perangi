Kenapa PERANGI?

🚫 Filter DNS on-device

Situs judol & pinjol ilegal diblokir sebelum sempat dibuka. Semua diproses lokal di HP — data tidak dikirim ke server mana pun.

🔤 Blokir pola kata

Bandar ganti domain tiap hari? Pola khas seperti togel, gacor, maxwin tetap kena blokir otomatis.

👨‍👩‍👧 Mode Orang Tua

Kunci proteksi dengan PIN. Kalau dimatikan paksa dari luar, HP kasih peringatan.

🆘 Tombol Darurat

Lagi pengen main? Satu tap: ingat berapa ratus juta yang bakal hangus, plus saran hubungi orang terdekat.

🧮 Kalkulator Rugi

Hitung berapa uangmu yang dibakar judol & bunga pinjol — angkanya bikin sadar.

🏦 Cek Pinjol OJK

Cek status pinjol dari direktori OJK: legal, ilegal, atau tidak dikenal.

📱 Scan Aplikasi

Deteksi APK judi/pinjol ilegal yang terinstal — yang lolos filter DNS pun ketahuan.

📝 Laporan Komunitas

Temu situs baru? Laporkan — lindungi pengguna lain.

Cara Install

  1. Download APK dari tombol di atas.
  2. Izinkan install — Android akan minta izin "install dari sumber tak dikenal", izinkan untuk browser/WhatsApp yang kamu pakai.
  3. Buka PERANGI dan ikuti 3 langkah onboarding (aktifkan VPN lokal).
  4. Matikan Secure DNS di Chrome & DNS Pribadi di Setelan HP — aplikasinya memandu caranya.

Tanya Jawab

Apakah data saya dikirim ke server?

Tidak. Penyaringan DNS berjalan 100% lokal di HP (VPN lokal, bukan VPN betulan). Satu-satunya koneksi keluar: cek pembaruan blocklist & aplikasi dari GitHub.

Kenapa tidak ada di Play Store?

Kebijakan Play Store melarang aplikasi DNS blocker on-device. Makanya PERANGI didistribusikan langsung sebagai APK dari GitHub resmi ini.

Apakah benar-benar gratis?

Ya. Gratis, tanpa iklan, tanpa akun. Dibuat untuk misi sosial: Indonesia bebas judol & pinjol ilegal.

Anak saya bisa mengakali dengan uninstall?

Di HP biasa, ya — tidak ada aplikasi yang bisa mencegah uninstall tanpa menjadi malware. Gunakan Mode Orang Tua + alarm, dan untuk anak kecil kombinasikan dengan Google Family Link.
